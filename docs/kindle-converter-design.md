# Kindle Note Converter Design Specification

## 1. Project Overview
The purpose of this program (`Convertor.py`) is to transform a structured `My Clippings.csv` file into a professionally formatted `.xlsx` Excel workbook. The final output will organize notes by book, sorted by location, with specific aesthetic and layout formatting for optimal readability.

## 2. Core Requirements
### 2.1 Input and Output
- **Input File**: `My Clippings.csv` (generated by `KindleParser.py`) located in the current working directory.
- **Output File**: An `.xlsx` file named `Clippings-YYYYMMDDHHMMSS.xlsx` (where timestamps are accurate to the second).

### 2.2 Structural Organization
- **Sheet per Book**: Each unique book title in the CSV will have its own dedicated worksheet (Sheet).
- **Sheet Naming**: The Sheet name will be the book title. 
  - **Constraint**: If a book title exceeds 31 characters, it must be truncated to 31 characters to comply with Excel's limitation.
- **Data Sorting**: Within each sheet, entries must be sorted in ascending order based on the `位置` (Location) numerical value.

### 2.3 Table Layout and Formatting
- **Columns (5 Total)**:
  1. `位置` (Location) - Width: 15
  2. `页码` (Page) - Width: 10
  3. `摘录` (Excerpt) - Width: 100
  4. `笔记` (Note) - Width: 50
  5. `日期` (Date) - Width: 20
- **Row Styling**:
  - **Header Row (Row 1)**:
    - Font Size: 14
    - Style: Bold
    - Persistence: Frozen (Freeze Panes at A2)
  - **Data Rows**:
    - Font Size: 12
    - Default Font: System Default
  - **Row Height**: Dynamically adjusted based on the content of the `摘录` (Excerpt) cell to ensure all text is visible (Wrap Text enabled).

## 3. Technical Implementation
### 3.1 Tech Stack
- **Language**: Python 3.x
- **Primary Library**: `openpyxl` (used for complex XLSX structure and styling).
- **Packaging**: Designed to be compatible with `PyInstaller` for conversion to a standalone `.exe`.

### 3.2 Data Pipeline
1. **Read**: Load `My Clippings.csv` using `csv` module.
2. **Group**: Create a dictionary mapping `Book Title` $\rightarrow$ `List of Entries`.
3. **Sort**: For each book's list, perform a numerical sort on the `位置` column.
4. **Generate**: 
   - Create a new `openpyxl` Workbook.
   - For each book:
     - Create a Sheet (truncated name).
     - Write header $\rightarrow$ apply Header Style $\rightarrow$ apply Column Widths.
     - Write sorted data $\rightarrow$ apply Data Style $\rightarrow$ enable Wrap Text $\rightarrow$ adjust Row Height.
     - Set Freeze Panes.
5. **Export**: Save the workbook using a dynamic timestamped filename.

## 4. Robustness and Edge Cases
- **Sheet Name Validation**: Explicitly handle the 31-character limit for sheet names.
- **Empty Data**: Gracefully handle cases where the CSV is empty or missing.
- **Numerical Sorting**: Ensure `位置` is treated as an integer for sorting, not as a string (to avoid "10" coming before "2").
- **Character Encoding**: Use `utf-8-sig` for reading the CSV to ensure Chinese characters are handled correctly.
